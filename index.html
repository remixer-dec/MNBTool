M&BToolMount and Blade Warband companion

A launcher for Mount & Blade: Warband on Android

Engine mods, a mobile patch and translations for the game you already own.

Download the latest release

Features

Bug fixes and improvements

Fixes many of the game's bugs and issues, with performance and gameplay improvements.

ARMv8 static recompilation

Provides an ARMv8 variant through static recompilation, built from the ARMPORT project work.

Advanced language support

Community and machine translations for the game and modules, installed from the library.

Touch, gamepad, keyboard

Configurable controls for touch screens, gamepads and keyboard with mouse.

Modules

Run PC modules, with compatibility notes in the library.

Mod SDK

Build your own native mods for ARMv7 and ARM64. The SDK is attached to each release.

Languages

The game's own: English, Čeština, Français, Deutsch, Magyar, Polski, 简体中文, 繁體中文, Español, Türkçe. Built into the launcher: Русский. From the library: Italiano, Português (Brasil), 한국어, Tiếng Việt, Bahasa Indonesia, עברית, العربية, فارسی, اردو, ไทย.

You need the full game. M&BTool contains no game assets or game files. It is only a launcher with mods, a mobile patch and translations, and it works with your own legally obtained copy of Mount & Blade: Warband.
